# Java CI/CD Docker Deployment

## Project Overview

This project demonstrates the deployment of a Java web application using Docker, Apache Tomcat, Maven, Jenkins, and AWS EC2. The objective is to build a CI/CD pipeline that automates application building, testing, and deployment.

The application is packaged as a WAR file using Maven and deployed on an Apache Tomcat server running inside a Docker container. Jenkins is used to automate the build and deployment workflow, while Git and GitHub provide version control and source code management.

## Objectives

- Build and package a Java web application using Maven.
- Containerize the application using Docker.
- Deploy the application on Apache Tomcat.
- Use Jenkins to automate the CI/CD pipeline.
- Store and manage project source code using Git and GitHub.
- Host the application infrastructure on AWS EC2.

## Technologies Used

- AWS EC2
- Ubuntu Linux
- Git and GitHub
- Jenkins
- Java 21
- Apache Maven
- Docker
- Apache Tomcat 10.1

## Current Implementation

The Java web application has been built successfully using Maven and deployed inside a Docker container running Apache Tomcat. The application has been accessed and verified through a web browser.
